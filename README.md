# Laksam Local Service

A local service discovery and booking platform for Laksam.

## Planned modules
- Customer website
- Provider dashboard
- Admin panel
- Service and category management
- Provider verification
- Booking management
- Reviews and reports

## Suggested stack
- Next.js + TypeScript
- Tailwind CSS
- PostgreSQL
- Supabase Auth / Storage

## MVP scope
- Search and browse services
- Provider profiles
- Call / WhatsApp
- Booking requests
- Provider registration
- Admin verification
- Admin management of users, providers, services, bookings, reviews and reports
