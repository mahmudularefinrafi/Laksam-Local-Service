# Admin Panel

## Dashboard
- Total users
- Total providers
- Pending verification
- Total bookings
- Pending bookings
- Completed bookings
- Average rating
- Popular services

## Provider Management
- Search/filter providers
- View provider profile
- Approve/reject verification
- Suspend/unsuspend provider
- Edit provider information

## User Management
- Search users
- View profile and booking history
- Block/unblock account

## Catalog Management
- Categories CRUD
- Services CRUD
- Laksam area CRUD
- Activate/deactivate catalog items

## Booking Management
- Search bookings
- Filter by status/date/service/area
- View booking details
- Correct status when needed

## Reviews
- Review moderation
- Hide/show review
- View linked booking

## Reports
- Review provider/customer reports
- Add admin notes
- Resolve/dismiss reports

## Access control
- Only admin role can access /admin routes and admin APIs.
- Never trust a client-side role check alone; enforce authorization on the server.
